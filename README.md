# 《星之暗面》 Dark Side of the Star

一款五章的网页游戏。你是一颗发不出光的星，爱上了一颗不需要你的星。

**双击 `index.html` 就能玩**，不用安装、不用服务器、不用网络。
（如果浏览器限制本地文件，用 `python -m http.server` 起个本地服务再打开也行。）

---

## 操作

| 键 | 作用 |
|---|---|
| `A` / `D` 或 `←` / `→` | 左右移动 |
| `W` / `空格` | 减缓下坠（第五章是喷气推进，要烧光） |
| `S` / `↓` | 加速下坠 |
| **左键（按住）** | 凝视：时间放慢到 0.45×（第二章），但更容易被她发现 |
| **右键 / Shift（按住）** | 献出光：第三章让你伪装成亮星，第四章托住她 |
| `Esc` | 暂停 / 温柔模式 |

**没有"上升"键。** 前四章你只能决定自己掉得多慢，上升永远来自她的光。第五章是个例外——那里没有她的光。

## 五章

| 章 | 名字 | 时长 | 你要做的事 |
|---|---|---|---|
| 一 | 引力 | ≈2:40 | 追上她。靠近才有力气飞，掉了会被雾推回来，不会死 |
| 二 | 余光 | ≈2:40 | 活在她的余光里。她回头时，绕到她背后 |
| 三 | 群星 | ≈2:40 | 借别人冷光苟活，或把自己点燃，假装成一颗亮星 |
| 四 | 风雨 | ≈2:20 | 她坠落，你托住她。分光给她，用身体挡陨石 |
| 五 | 暗面 | **地狱** | 她的光照不到这里。下坠 9000 米，集齐 100 颗星，死一次从头开始 |

## 结局

第五章井底有两个结局，取决于两件事：

- 你到底剩多少光（一路喷气会烧光；收一颗星回 1.6 点）；
- 最后那 8 秒，你有没有按住右键把最后的光给她。

**点亮**：她抵达顶点，整片星海为她亮起。你熄灭了，她的轨道旁多了一颗几乎看不见的星。
**沉默**：她一个人站在暗处，抬起头，什么也没看见。你们都还在，只是没有光。

## 生命与失败

**前四章**：左上角有生命条（100 点）。

| 情况 | 扣血 |
|---|---|
| 摔进下方的雾 | 30 |
| 被她看见（第二章暴露满格） | 12 |
| 伪装被识破（第三章） | 12 |
| 撞上陨石（第四章） | 22 |

血掉光，这一章从头开始。

**第五章（地狱）没有血条**，规则更简单也更残忍：

- 井里散落 **100 颗星**，必须全部收齐才能到达井底；
- 井底差一颗星，整关从头再来；
- **死一次，星星清零，回到井口，从头开始**；
- 障碍（旋转光刃 / 横移方块 / 碎片）位置和相位完全固定，可以背板——这是刻意的，苦练必须有用。

## 温柔模式

第五章第一次玩可能会死几十次。暂停菜单里可以打开"温柔模式"：危险物转速和移动速度降低 15%。
默认关闭——你想要的地狱模式，是真的地狱。

## 文件

```
index.html          页面结构、标题 / 章节卡 / 信件 / 结局的 DOM
css/style.css       全部样式（16:9 自适应，随窗口缩放）
js/audio.js         程序化配乐：她的主题是完整旋律，你的主题低八度、缺三个音
js/game.js          引擎 + 五章全部逻辑（约 1200 行，无依赖）
test/               无头测试（Node）：跑完五章、验证核心机制
```

## 测试

```bash
node test/headless.js   # 五章跑通、结局流程、生命条、差星重来、死亡清零
node test/behavior.js   # 跟随、被发现、献光、托举、喷气五项机制
node test/hell.js       # 第五章：100 星可达、通关时长、难度量级、重来确定性
```

用假 DOM + 假 Canvas 在 Node 里跑真实的游戏循环，所以能测逻辑，测不了画面。

## 一些说明

- 所有画面都是 Canvas 程序化绘制：没有一张图片、没有一个音频文件。光晕是三层叠加圆的加色混合。
- 第五章的星星路径是固定的正弦蛇形（越深摆幅越大），障碍位置与相位完全固定——死亡后一切重置，所以可以背板。
- 实测数据（测试机器人）：单程 63 秒可收齐 100 颗星；只会闷头追星的机器人每次都死在同一个位置（第一组转子，y≈1352，12 颗星处）——难度墙在那里，但每一面墙都有时间窗。
- 音乐是 WebAudio 即时合成的：她的是完整旋律，你的是同一段旋律降八度并去掉三个音。最后一章两者第一次同时出现，但那时你已经没有声音了。
